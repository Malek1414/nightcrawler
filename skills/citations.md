# Citations (School and University)

Use this when sources are needed for class, a presentation, a term paper, or university work.

## Complete references
Every source needs: author (or institution), title, year or date, where it was published, and the access date for online sources.
- Web page: Last name, First name (Year): Title. URL (accessed YYYY-MM-DD).
- Book: Last name, First name (Year): Title. Edition. Place: Publisher, page.
- Article: Last name, First name (Year): Title. In: Outlet, date. URL (accessed YYYY-MM-DD).
- If there is no author: name the institution or use "Anon."; if there is no year: "n.d.". But check the page itself first (article header, footer, imprint or about page) before you claim that.
- If a specific style is required (APA, MLA, Chicago, Harvard), follow it instead of the pattern above.

## Never take metadata on trust
- Verify author, year, and title from the opened page itself, not from the search snippet (snippets are often wrong or outdated).
- If an article reports on a study: find and cite the original study, and cite the article only in addition, if at all.
- Before output, check: does every URL really resolve to the claimed document? Are there duplicates in the list?

## Quotation vs. paraphrase
- Direct quotation: in quotation marks, character-exact, with the exact location (page or section). Only when the wording itself matters.
- Paraphrase (default): your own words plus a reference ("cf. source").
- Avoid secondary citations; if unavoidable, mark them as "cited in".

## Source quality
- Ranking: primary source or study, then specialist literature and reputable journalism, then encyclopedias, and last blogs and forums.
- Wikipedia: a good starting point, but cite the references it links to, not the article itself.
- Central claims need at least 2 independent sources.

## Output
- Cite in the text with [1], [2], and below that a "Sources:" list with complete references.
- On request, save with save_research as a note so the references are kept for the bibliography.
